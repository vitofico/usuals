# Android purchase review verification

Verified on 2026-10-25. Android offers **Review your usuals** above the list, outside typing and
shopping mode. The old suggestion cards are replaced by one review sheet.

## Automated checks

```sh
scripts/dgradle test :app:assembleDebug :app:assembleDebugAndroidTest :app:lintDebug --no-watch-fs
```

- The full Docker unit-test suite passes; opt-in live tests are skipped.
- Android lint passes with no diagnostics in the new review files.
- Native alignment passes for all 12 packaged libraries across four ABIs.
- The staged credential scan passes.

Coverage includes distinct-shop frequency, age ordering, confirmed aliases,
the last-eight-shop window, cold starts, the 24-hour boundary, repeat rules,
mute and snooze choices, checked rows, duplicate taps, failed writes, safe Undo,
late responses after closing, shared-list updates and list changes. Returning
after the freshness boundary refreshes eligibility without a database write.
A stale mute cannot stop a repeat rule enabled after the card was shown.

## Emulator flow

`ReviewDeviceTest.completeReviewFlowWorksOffline` uses real Room storage,
production repository adapters and `ListScreen`, with a fixed clock and
synthetic history. It does not connect to an account or server.

Both scenarios pass on an Android 16 / API 36 arm64 emulator with networking
disabled:

| Scenario | Result |
| --- | --- |
| Normal display, light theme | Pass |
| Actual 320 dp display width, 160% system font scale, dark theme | Pass |

The scenario opens the review from the list; checks its factual explanation;
skips and undoes; adds and safely undoes; adds again; hides an item; closes and
reopens without losing the addition; completes ten items and reviews the next
round; observes another writer adding an item; and switches lists. It verifies
that review adds carry no inferred quantity and that Skip changes neither
purchase history nor preferences.

Run on a disposable emulator:

```sh
adb -s emulator-5570 shell am instrument -w -r -e class io.theficos.usuals.ReviewDeviceTest -e replayQa synthetic io.theficos.usuals.debug.test/androidx.test.runner.AndroidJUnitRunner
adb -s emulator-5570 shell wm density 540
adb -s emulator-5570 shell settings put system font_scale 1.6
adb -s emulator-5570 shell am instrument -w -r -e class io.theficos.usuals.ReviewDeviceTest -e replayQa synthetic -e replayLargeText true -e replayDark true io.theficos.usuals.debug.test/androidx.test.runner.AndroidJUnitRunner
```

The 540 dpi override gives 320 dp on the tested 1080-pixel display. Screenshots
of the card, round completion and resulting list are saved in the debug app's
cache. The capture waits for the display compositor as well as Compose.

The review uses existing shopping data and adds no schema, dependency or network
request. Its ordering is factual frequency followed by purchase age; inferred
interval predictions remain disabled pending the established real-history gate.
