# Vision

Usuals is a shopping list with memory: it helps a household remember what to
buy using purchase history that stays on the phone. Voice, keyboard, shared
text and barcode capture keep the list useful without a model. Keyboard entry
always works offline; voice depends on the installed Android speech service.
English is the default UI; input languages and display languages are independent.

One living list spans shops. Finish files checked rows from their final state,
using the time each row was checked. Unchecked rows carry forward. Undo,
portable history and dated imports make that memory something a person keeps.
A text share supports a partner without any account.

Memory should help without making the list untrustworthy. Only a person's
explicit repeat rule adds automatically. A short review of recent purchase
history offers Add and Skip, with safe Undo. Skip affects only that session;
hiding a suggestion is explicit. Amounts are hints until tapped, and name
corrections are reviewed together after capture. Automatic typo matching is optional and starts
off; quantities and item qualifiers are preserved. Interval predictions stay off
until real-history replay beats last-trip and staple baselines; the current
build orders the history review by recent shop frequency, then elapsed time.

Recipe links become reviewed ingredients, rather than a recipe collection.
Structured recipes are read on the device. An optional model, off by default,
serves only prose recipes. An optional barcode lookup offers a confirmed name
and category. Neither service is needed for the list or its purchase memory.
A store filter and local home-screen widget support shopping with that list.

Local reminders and carefully labelled product nutrition/allergen information
are implemented. A voice tile and evidence-backed bought-together suggestions
remain later work. Optionally, a self-hosted Usuals server keeps an account's
lists in sync between phone and browser and shares them with other accounts on
that server; the server can read those lists. Cluster deployment needs the
maintainer's approval.

Retailer integrations, price memory, pantry tracking, meal planning, recipe
storage, AI chat, analytics and advertising are outside the product. Browser
accounts and optional SSO control sign-in; a list is shared only by one of its
members.
The Android app remains Apache-2.0 and contributions follow the existing CLA.
See the [roadmap](roadmap.md) for implemented scope and release limits.
